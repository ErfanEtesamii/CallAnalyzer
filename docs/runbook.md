# عیب‌یابی
| علامت | علت | راه‌حل |
|---|---|---|
| «نشست پنل منقضی شده» | کوکی پنل منقضی | وارد پنل شوید و دوباره تلاش کنید |
| دانلود از پنل شکست می‌خورد | گواهی self-signed | آدرس پنل را در تب جدید باز و گواهی را بپذیرید |
| خطای CORS | `ALLOWED_ORIGINS` | `chrome-extension://<ID>` را اضافه کنید |
| `budget_exceeded` | سقف روزانه | `DAILY_BUDGET_USD` را بالا ببرید |
| `stt_unavailable` | کلید/وابستگی STT | `make doctor` |
